
# Testes de Integração com GenAI

## Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica da Unidade III, com o objetivo de explorar o uso da Inteligência Artificial Generativa (GenAI) no apoio à elaboração de testes de integração.

O cenário escolhido simula a comunicação entre dois serviços REST:

- API de Pedidos: responsável pelo registro de pedidos.
- API de Estoque: responsável pela consulta e atualização da disponibilidade dos produtos.

## Objetivos

- Utilizar diferentes tipos de prompts para gerar testes de integração.
- Criar cenários positivos e negativos.
- Identificar possíveis falhas na comunicação entre serviços.
- Avaliar a qualidade dos casos de teste gerados por GenAI.

## Estrutura do projeto

- `prompts/prompts.md`: prompts utilizados com a LLM.
- `testes/casos-de-teste.md`: casos de teste gerados.
- `analise/resultados.md`: análise dos resultados e ajustes realizados.

## Tecnologias e recursos

- Inteligência Artificial Generativa (LLM).
- Testes de integração.
- APIs REST.
- GitHub para documentação e versionamento.

## Considerações finais

A GenAI foi utilizada como copiloto na elaboração dos cenários de teste, contribuindo para ampliar a diversidade dos casos e apoiar a identificação de possíveis falhas de integração.
